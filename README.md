## ✅ 내 담당 역할

### 1. K-means 군집화 분석
- 전국 시군구를 **보조금 · 충전 인프라 · 소득 · 인구** 4개 변수로 분류
- StandardScaler 표준화 후 PCA(2차원)로 차원 축소
- **Elbow Method + Silhouette Score(0.514)** 기반으로 k=4 결정
  - K=2는 실루엣 점수(0.786)가 가장 높지만 도시/지방 단순 구분 → 프로젝트 목적에 부합하지 않음
  - K=4는 점수도 양호하고 지역별 특성 차이도 뚜렷해 해석력·효율성 균형

**클러스터 결과**

| 클러스터 | 지역 특성 | 충전소 평균 | 보조금 평균 |
|----------|-----------|-------------|-------------|
| 0 🔴 농어촌·비수도권 (89개) | 인구·소득·충전소 모두 낮음 | 23대 | 1,222만원 |
| 1 🔵 광역시·경기 주요도시 (14개) | 부산·대구 등 광역시, 수원·고양·화성 등 | 293대 | 846만원 |
| 2 🟢 서울특별시 단독 (1개) | 모든 지표 전국 1위 | 1,468대 | 640만원 |
| 3 🟡 수도권 외곽·강원·경상 중소도시 (56개) | 인프라·소득 중간, 보조금 높음 | 54대 | 938만원 |

### 2. SHAP 요인분석 해석
- **충전소 수 · 시장 성숙도(months_since_start) · 보조금 지급 여부** 순으로 구매에 영향
- 약 80개월(아이오닉5 출시, 2021년)을 기점으로 전기차 등록대수 폭발적 증가
- 충전소 수 증가가 단독으로 즉각적인 구매 심리 자극으로 연결되지 않음 → 중장기적 관점 필요
- 1인당 보조금 감소 + 지원 대수 증가 정책에도 시장 성장 → 보조금 의존도 낮아지는 추세 확인

### 3. 지역별 정책 방향 제안 보고서 작성
- 클러스터 0·3 → **충전소 인프라 우선 확충** (중장기 구매 환경 조성)
- 클러스터 1·2 → 보조금보다 **세제혜택·충전비 지원** 등 비용 부담 완화 정책 제안
- 시장 성숙기 이후 유가 민감도 상승 → 내연기관 대비 가격 경쟁력 유지 수준의 보조금 필요

## 💡 주요 인사이트

- 보조금이 높아도 충전 인프라가 부족한 농어촌(클러스터 0)은 EV 보급률 낮음
- 서울(클러스터 2)은 보조금 최저이지만 충전소·소득 전국 1위 → 보조금 의존도 낮음
- 아이오닉5 출시(2021년)는 기술·인프라 축적이 발현된 기점
- 전기차 판매는 **봄·가을 상승 / 여름·겨울 하락** 계절성 패턴 존재
